## Project Overview
A 4-page personal portfolio site built with HTML5 and CSS3 for INFR3120 Assignment 1.

## Pages
- **index.html** - Home page with navigation
- **about.html** - Photo, intro, embedded video
- **projects.html** - 5 projects
- **contact.html** - Contact form with validation

## Viewport Dimensions
- **Desktop (full.css)**: 960px and wider
- **Tablet (tablet.css)**: 481px to 960px
- **Phone (phone.css)**: 480px and narrower

I chose these dimensions based on the standard 960px grid design taught in class.

## Gradients Used
- **Linear gradient (45deg)**: body background
- **Angled linear gradient (135deg)**: header and footer

## Color Scheme (from Adobe Color)
- #3D4899 (Dark Blue) - h2 headings, form borders
- #962EFF (Purple) - gradients, h3 headings
- #B4C73C (Lime Green) - h2 underline, hover highlights
- #E6C11E (Gold) - header h1, footer links
- #56F074 (Light Green) - optional accent

## Code Sources
All code is based on the course lectures (Week 1-4). No external code used.

- CSS validated with W3C CSS Validator
